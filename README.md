# ESP32 Smart Attendance System

An embedded attendance system built using ESP32, a 4x4 keypad, LCD display, and a custom PCB. The system allows students to enter their roll numbers and stores attendance records with date and time.

## Features

- Roll number entry using keypad
- LCD user interface
- Stores attendance
- Password-protected admin mode
- Duplicate attendance prevention
- Custom PCB
- Expandable to Wi-Fi and cloud storage

## Hardware Used

- ESP32
- 4x4 Matrix Keypad
- 16x2 I2C LCD
- DS3231 RTC
- Custom PCB
- Power Supply

## Software

- Arduino IDE
- C++
- ESP32 Board Package
